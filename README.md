# Lucas Carvalho Cordeiro

**Analista de Sistemas e Inovação | Engenharia de Software | Inteligência Artificial Aplicada**

Atuo no desenvolvimento de sistemas corporativos, automação de processos e soluções orientadas a dados. Sou graduando em **Inteligência Artificial pela FIAP** e tenho formação prática em qualidade e testes de software (QA).

Meu trabalho combina desenvolvimento de aplicações, experimentação em Machine Learning e práticas de engenharia voltadas à **confiabilidade, validação e rastreabilidade**.

## Áreas de atuação

- **Engenharia de software:** desenvolvimento de aplicações web e APIs, modelagem de dados e automação de processos.
- **Inteligência artificial aplicada:** Machine Learning, recuperação de informações, embeddings e avaliação de sistemas de busca.
- **Qualidade de software:** testes automatizados, validação de APIs, documentação técnica e integração contínua.
